# AI-assisted Spam Detection Module

## Назначение

Модуль выявляет признаки использования генеративного ИИ при создании спам-писем и кампаний. Анализирует не только текст, но и изображения, также как и прочие файлы в письме.

## Принцип работы

1. Парсинг входящего письма (MIME, text/plain или text/html)
2. Извлечение мультисигнальных признаков (текст, структура, заголовки, ссылки)
3. Классификация через легковесную CNN + анализ через Qwen API
4. Выдача JSON-отчета с оценками по каждому элементу письма
