# Dataset pipeline

Этот каталог содержит подготовку данных, извлечение признаков и baseline-эксперименты. Рабочие forensic-компоненты проекта находятся вне него, в `inference/` и пакете `src/`.

## Структура

- `data/raw/` — неизменяемые исходные наборы по источникам.
- `data/interim/` — промежуточные таблицы, в том числе `features.csv` и `labels.csv`.
- `data/processed/` — очищенные и объединённые наборы данных.
- `src/` — переиспользуемый код: конфигурация, разбор структуры письма и извлечение признаков.
- `scripts/` — точки запуска для подготовки, проверки, обучения и объяснения модели.
- `reports/` — метрики и визуализации экспериментов.

## Конфигурация путей

Все файловые пути централизованы в `src/config.py`. Локальные значения задаются в `dataset/.env`; пример доступен в `dataset/.env.example`. Значение переменной окружения имеет приоритет над `.env` и удобно для CI.

Ключевые переменные:

- `DATASET_PROCESSED_DATASET` — результат подготовки набора;
- `DATASET_PROCESSED_DATASET_CLEAN` — текущий очищенный набор для интерактивного предсказания;
- `DATASET_FEATURE_TABLE` и `DATASET_LABEL_TABLE` — признаки и метки для baseline/SHAP;
- `DATASET_BASELINE_RESULTS` и `DATASET_SHAP_SUMMARY` — артефакты оценки;
- `DATASET_TEMP_IMAGES` — временные изображения для необязательных OCR-признаков.

Запускайте сценарии из корня репозитория как модули, например:

```bash
python -m dataset.scripts.clean
python -m dataset.scripts.predict_email
python -m dataset.scripts.train_baseline
```

`prepare_data.py` требует исходные файлы, пути к которым указаны в `.env`. `train_baseline.py` и `explain_model.py` требуют предварительно сформированные `features.csv` и `labels.csv` в `data/interim/`; создание этих таблиц является следующим отдельным этапом реорганизации.

Обработка изображений и OCR в `src/text_features.py` остаётся необязательной: без `easyocr` соответствующие признаки безопасно принимают базовые значения. Сетевые загрузки изображений не являются частью базового текстового сценария и в дальнейшем должны быть вынесены в отдельный image-feature pipeline.
